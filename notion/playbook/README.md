# X Writer Playbook SVG set

This set teaches the X writing workflow through memorable non-boxed visual metaphors.

## Locked construction

- SVG only, 1600 by 900 viewBox, transparent root.
- No canvas fill, card frame, panel grid, or box-in-box layout.
- Coinvo bright palette: green `#34D399`, cyan `#22D3EE`, yellow `#F5C518`, purple `#A855F7`, orange `#F97316`, red `#F04848`.
- One concept per image, expressed through a physical, scientific, or philosophical model.
- Short labels only. The chapter text carries the full instruction.
- Theme-aware text for dark and light viewing.
- Title, one-line subtitle, divider, then the visual.
