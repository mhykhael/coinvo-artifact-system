## System Rules

1. Edit the SVG source rather than rasterizing a replacement.
2. Preserve the six locked colors and their semantic roles.
3. Use only source backed facts and current doctrine.
4. Keep the title, subtitle, divider, and design sequence.
5. End at the design. Do not add a trailing footer.
6. Replace outdated visuals instead of stacking contradictory versions.
